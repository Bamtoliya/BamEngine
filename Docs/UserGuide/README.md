# BamEngine 사용자 가이드

게임 제작자를 위한 시스템별 사용법. 엔진 내부 설계와 구현 계획은 상위 `Docs/`의 기술 문서에서 별도로 관리한다.

- 기준 환경: Windows x64, Visual Studio 2026, CMake, Ninja Debug
- 기준 커밋: [`770e3adb`](https://github.com/Bamtoliya/BamEngine/commit/770e3adb81e3a4e9ea692996df09942e74587f28), 2026-11-28 KST
- 검증 범위: 이전 통합 가이드의 정적 조사 결과를 분리했다. 이번 분리 작업은 추가 코드 조사나 빌드·실행 검증을 수행하지 않았다.

## 상태 표기

이 문서는 엔진 내부 설계 설명보다 실제로 게임을 만드는 순서에 집중한다. 코드에서 진입점과 처리 경로를 확인한 기능과 파일 목록 또는 과거 문서만 확인한 기능을 구분한다.

| 표기 | 의미 |
|---|---|
| 코드 확인 | 소스에서 관련 인터페이스 또는 동작 경로를 직접 확인함. 실행 성공을 보증하지 않음 |
| 문서 확인 | 저장소의 사용자/설계 문서에 설명된 기능. 최신 구현과 일부 차이가 있을 수 있음 |
| 파일 확인 | 컴포넌트 또는 패널 헤더가 존재함. 실제 UI 연동, 기능 완성도는 추가 확인 필요 |
| 제안 | 제작을 위한 예시 구성. 엔진 기본 설정 또는 검증된 프리셋이 아님 |

메뉴 이름은 영어 기준 또는 소스의 의미를 사용한다. 한국어 로캘 및 창 크기에 따라 표시가 달라질 수 있다. 기존 문서에서 2026-11-20 Ninja Debug CTest 44/44 통과가 기록되어 있으나 최신 커밋의 테스트 결과로 간주하지 않는다.
